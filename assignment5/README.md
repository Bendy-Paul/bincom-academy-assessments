# Bincom Assignment 5 - ToDo App

A minimal ToDo app built with **PHP, MySQLi, HTML, and CSS**. Tasks are stored in a MySQL database.

## Features

- Add a task
- Mark a task as done / undo
- Delete a task

## Setup

1. Start **Apache** and **MySQL** in XAMPP.
2. Import `database.sql` in phpMyAdmin (`http://localhost/phpmyadmin` > Import).
3. If your MySQL password is not empty, edit `config.php`.
4. Open `http://localhost/bincom/assignment5/`.

## Files

```text
assignment5/
├── index.php      # Add, list, complete and delete tasks
├── config.php     # MySQLi connection
├── database.sql   # Database and table
├── style.css      # Basic styling
└── README.md
```
