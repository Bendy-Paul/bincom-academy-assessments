# Bincom Assignment 2 - Simple To-Do App

A clean and lightweight To-Do application built using **HTML and CSS only**. This project was created as part of the Bincom Academy assessment.

- **GitHub Repository**: [https://github.com/Bendy-Paul/bincom-academy-assessments/tree/main/assignment2](https://github.com/Bendy-Paul/bincom-academy-assessments/tree/main/assignment2)

---

## 📌 Project Overview

This project demonstrates how interactive user interfaces can be created with pure HTML5 and CSS3 without using any JavaScript or external libraries. By taking advantage of HTML form elements (`<input type="checkbox">` and `<label>`) and the CSS `:checked` pseudo-class, users can toggle tasks between pending and completed states.

---

## ✨ Features

- **Pure HTML & CSS**: No JavaScript or third-party frameworks required.
- **Interactive Checklist**: Click anywhere on a task item or checkbox to toggle its completed state.
- **Dynamic Visual Feedback**: Completed tasks display a strikethrough effect and dimmed text color.
- **Responsive & Clean UI**: Centered card layout that adapts cleanly to different screen sizes.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup, form controls (`<input type="checkbox">`), and list structures (`<ul>`, `<li>`).
- **CSS3**: Flexbox for layout alignment, `:checked` pseudo-class for state toggling, transitions, and custom styling.

## 🚀 How to Run the Application

You can view and test this project in two ways:

### Option 1: Direct File Open
1. Navigate to the project directory:
   ```
   C:\xampp\htdocs\bincom\assignment2\
   ```
2. Double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, etc.).

### Option 2: Using Localhost (XAMPP)
1. Start the **Apache** server from the XAMPP Control Panel.
2. Open your web browser.
3. Visit the URL:
   ```
   http://localhost/bincom/assignment2/
   ```
